================================================================================
        CUSTOM MCP SERVER DEMO - STEP BY STEP GUIDE
        Building a To-Do Task Application with Custom MCP Server
================================================================================

OVERVIEW:
This demo will show you how to create a custom MCP (Model Context Protocol)
server using a simple C# Console Application. The example will be a TO-DO
TASK application that manages tasks and can be integrated with Claude.

================================================================================
PART 1: WHAT IS MCP?
================================================================================

MCP (Model Context Protocol) is a protocol that allows Claude to connect to
external tools and services. Think of it as a "bridge" between Claude and
your applications.

Example:
- Without MCP: Claude knows only what you tell it in the chat
- With MCP: Claude can directly access your To-Do app, fetch tasks, create
  tasks, etc.

================================================================================
PART 1A: MCP PRIMITIVES (Building Blocks)
================================================================================

MCP has three main PRIMITIVES (core concepts) that Claude uses:

1. RESOURCES
   What: Data that the server provides
   Example: Individual to-do task, user profile, document content
   Think of: "What information do you have?"

   In our To-Do app:
   - Resource 1: List of all tasks (todo://all-tasks)
   - Resource 2: Specific task by ID (todo://task/1)
   - Resource 3: Completed tasks (todo://completed-tasks)

2. TOOLS
   What: Actions/Functions the server can perform
   Example: Create task, update task, delete task
   Think of: "What can you do?"

   In our To-Do app:
   - Tool 1: create_task() - Creates a new task
   - Tool 2: update_task() - Modifies existing task
   - Tool 3: delete_task() - Removes a task
   - Tool 4: complete_task() - Marks task as done
   - Tool 5: get_tasks() - Retrieves all tasks

3. PROMPTS
   What: Pre-built prompt templates for specific scenarios
   Example: "Generate a task summary", "Suggest task priorities"
   Think of: "What instructions should I give you?"

   In our To-Do app:
   - Prompt 1: "summarize_tasks" - Summarize all pending tasks
   - Prompt 2: "organize_tasks" - Suggest task organization
   - Prompt 3: "task_analysis" - Analyze task patterns

STEP 4: CREATE TODO SERVICE CLASS
================================================================================

4.1 Create a new file: TodoService.cs

CONTENT:
--------
using System;
using System.Collections.Generic;
using System.Linq;

namespace TodoMcpServer
{
    public class TodoService
    {
        private List<TodoItem> todos = new List<TodoItem>();
        private int nextId = 1;

        // GET ALL TODOS
        public List<TodoItem> GetAllTodos()
        {
            return todos.OrderBy(t => t.CreatedDate).ToList();
        }

        // GET TODO BY ID
        public TodoItem GetTodoById(int id)
        {
            return todos.FirstOrDefault(t => t.Id == id);
        }

        // CREATE NEW TODO
        public TodoItem CreateTodo(string title, string description)
        {
            var todo = new TodoItem
            {
                Id = nextId++,
                Title = title,
                Description = description,
                IsCompleted = false,
                CreatedDate = DateTime.Now
            };
            todos.Add(todo);
            return todo;
        }

        // UPDATE TODO
        public TodoItem UpdateTodo(int id, string title, string description, bool isCompleted)
        {
            var todo = GetTodoById(id);
            if (todo != null)
            {
                todo.Title = title;
                todo.Description = description;
                todo.IsCompleted = isCompleted;
            }
            return todo;
        }

        // DELETE TODO
        public bool DeleteTodo(int id)
        {
            var todo = GetTodoById(id);
            if (todo != null)
            {
                todos.Remove(todo);
                return true;
            }
            return false;
        }

        // MARK TODO AS COMPLETED
        public TodoItem CompleteTodo(int id)
        {
            var todo = GetTodoById(id);
            if (todo != null)
            {
                todo.IsCompleted = true;
            }
            return todo;
        }
    }
}
--------

This class handles all to-do operations (Create, Read, Update, Delete).

  Name: delete_task
  Input: id (int)
  Output: Success boolean
  Example: Delete task 2

Tool 4: CompleteTask
  Name: complete_task
  Input: id (int)
  Output: Updated TodoItem with isCompleted = true
  Example: Mark task 1 as complete

STEP 5: CREATE MCP SERVER CLASS
================================================================================

5.1 Create a new file: McpTodoServer.cs

CONTENT:
--------
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using Newtonsoft.Json;

namespace TodoMcpServer
{
    public class McpTodoServer
    {
        private TodoService todoService;

        public McpTodoServer()
        {
            todoService = new TodoService();
        }

        // INITIALIZE SERVER
        public void Start()
        {
            Console.WriteLine("[MCP Server] To-Do Task Server Started");
            Console.WriteLine("[MCP Server] Listening for requests...");

            // Add sample data
            todoService.CreateTodo("Complete RetailApp", "Finish the MCP custom server demo");
            todoService.CreateTodo("Learn MCP Protocol", "Understand how MCP works");

            ListenForRequests();
        }

        // LISTEN FOR INCOMING REQUESTS FROM CLAUDE
        private void ListenForRequests()
        {
            while (true)
            {
                try
                {
                    string input = Console.ReadLine();
                    if (string.IsNullOrWhiteSpace(input)) continue;

                    // Parse JSON request
                    dynamic request = JsonConvert.DeserializeObject(input);
                    string action = request["action"];

                    string response = ProcessAction(action, request);
                    Console.WriteLine(response);
                }
                catch (Exception ex)
                {
                    Console.WriteLine(JsonConvert.SerializeObject(new
                    {
                        error = ex.Message
                    }));
                }
            }
        }

        // PROCESS ACTIONS
        private string ProcessAction(string action, dynamic request)
        {
            return action switch
            {
                "get_all_todos" => GetAllTodos(),
                "get_todo" => GetTodo((int)request["id"]),
                "create_todo" => CreateTodo((string)request["title"], (string)request["description"]),
                "update_todo" => UpdateTodo((int)request["id"], (string)request["title"],
                                           (string)request["description"], (bool)request["isCompleted"]),
                "delete_todo" => DeleteTodo((int)request["id"]),
                "complete_todo" => CompleteTodo((int)request["id"]),
                _ => JsonConvert.SerializeObject(new { error = "Unknown action" })
            };
        }

        // ACTION HANDLERS
        private string GetAllTodos()
        {
            var todos = todoService.GetAllTodos();
            return JsonConvert.SerializeObject(new { success = true, data = todos });
        }

        private string GetTodo(int id)
        {
            var todo = todoService.GetTodoById(id);
            return JsonConvert.SerializeObject(new { success = todo != null, data = todo });
        }

        private string CreateTodo(string title, string description)
        {
            var todo = todoService.CreateTodo(title, description);
            return JsonConvert.SerializeObject(new { success = true, data = todo });
        }

        private string UpdateTodo(int id, string title, string description, bool isCompleted)
        {
            var todo = todoService.UpdateTodo(id, title, description, isCompleted);
            return JsonConvert.SerializeObject(new { success = todo != null, data = todo });
        }

        private string DeleteTodo(int id)
        {
            bool deleted = todoService.DeleteTodo(id);
            return JsonConvert.SerializeObject(new { success = deleted });
        }

        private string CompleteTodo(int id)
        {
            var todo = todoService.CompleteTodo(id);
            return JsonConvert.SerializeObject(new { success = todo != null, data = todo });
        }
    }
}
--------

using System;
using System.Collections.Generic;
using Newtonsoft.Json;

namespace TodoMcpServer
{
    public class McpResources
    {
        private TodoService todoService;

        public McpResources(TodoService todoService)
        {
            this.todoService = todoService;
        }

        // Get all tasks as a resource
        public string GetAllTasksResource()
        {
            var todos = todoService.GetAllTodos();
            return JsonConvert.SerializeObject(new
            {
                resourceUri = "todo://tasks",
                resourceType = "list",
                description = "All to-do tasks",
                data = todos
            });
        }

        // Get completed tasks as a resource
        public string GetCompletedTasksResource()
        {
            var todos = todoService.GetAllTodos();
            var completed = todos.FindAll(t => t.IsCompleted);
            return JsonConvert.SerializeObject(new
            {
                resourceUri = "todo://tasks/completed",
                resourceType = "list",
                description = "Completed tasks",
                data = completed
            });
        }

        // Get pending tasks as a resource
        public string GetPendingTasksResource()
        {
            var todos = todoService.GetAllTodos();
            var pending = todos.FindAll(t => !t.IsCompleted);
            return JsonConvert.SerializeObject(new
            {
                resourceUri = "todo://tasks/pending",
                resourceType = "list",
                description = "Pending tasks",
                data = pending
            });
        }

        // Get specific task by ID
        public string GetTaskResourceById(int id)
        {
            var todo = todoService.GetTodoById(id);
            return JsonConvert.SerializeObject(new
            {
                resourceUri = $"todo://task/{id}",
                resourceType = "single",
                description = $"Task with ID {id}",
                data = todo
            });
        }
    }
}

using System;
using Newtonsoft.Json;

namespace TodoMcpServer
{
    public class McpTools
    {
        private TodoService todoService;

        public McpTools(TodoService todoService)
        {
            this.todoService = todoService;
        }

        // Tool: Create Task
        public string CreateTaskTool(string title, string description)
        {
            var todo = todoService.CreateTodo(title, description);
            return JsonConvert.SerializeObject(new
            {
                toolName = "create_task",
                success = true,
                message = $"Task created with ID {todo.Id}",
                result = todo
            });
        }

        // Tool: Update Task
        public string UpdateTaskTool(int id, string title, string description, bool isCompleted)
        {
            var todo = todoService.UpdateTodo(id, title, description, isCompleted);
            return JsonConvert.SerializeObject(new
            {
                toolName = "update_task",
                success = todo != null,
                message = todo != null ? "Task updated" : "Task not found",
                result = todo
            });
        }

        // Tool: Delete Task
        public string DeleteTaskTool(int id)
        {
            bool deleted = todoService.DeleteTodo(id);
            return JsonConvert.SerializeObject(new
            {
                toolName = "delete_task",
                success = deleted,
                message = deleted ? $"Task {id} deleted" : "Task not found",
                taskId = id
            });
        }

        // Tool: Complete Task
        public string CompleteTaskTool(int id)
        {
            var todo = todoService.CompleteTodo(id);
            return JsonConvert.SerializeObject(new
            {
                toolName = "complete_task",
                success = todo != null,
                message = todo != null ? "Task marked complete" : "Task not found",
                result = todo
            });
        }

        // Tool: Get All Tasks
        public string GetAllTasksTool()
        {
            var todos = todoService.GetAllTodos();
            return JsonConvert.SerializeObject(new
            {
                toolName = "get_all_tasks",
                success = true,
                message = $"Retrieved {todos.Count} tasks",
                result = todos
            });
        }
    }
}

Create a new file: McpPrompts.cs

CONTENT:

using System;
using System.Collections.Generic;
using Newtonsoft.Json;

namespace TodoMcpServer
{
    public class McpPrompts
    {
        private TodoService todoService;

        public McpPrompts(TodoService todoService)
        {
            this.todoService = todoService;
        }

        // Prompt: Summarize Tasks
        public string SummarizeTasks()
        {
            var todos = todoService.GetAllTodos();
            var completed = todos.FindAll(t => t.IsCompleted);
            var pending = todos.FindAll(t => !t.IsCompleted);

            return JsonConvert.SerializeObject(new
            {
                promptName = "summarize_tasks",
                template = "Please analyze these tasks and provide a summary",
                tasksSummary = new
                {
                    total = todos.Count,
                    completed = completed.Count,
                    pending = pending.Count,
                    completionPercentage = todos.Count > 0 ? (completed.Count * 100 / todos.Count) : 0
                },
                allTasks = todos
            });
        }

        // Prompt: Organize Tasks
        public string OrganizeTasks()
        {
            var todos = todoService.GetAllTodos();

            return JsonConvert.SerializeObject(new
            {
                promptName = "organize_tasks",
                template = "Suggest how to organize these tasks better",
                instruction = "Based on task titles and descriptions, suggest categories or groups",
                allTasks = todos
            });
        }

        // Prompt: Task Priority Analysis
        public string AnalyzeTaskPriority()
        {
            var todos = todoService.GetAllTodos();

            return JsonConvert.SerializeObject(new
            {
                promptName = "task_priority",
                template = "Analyze these tasks and suggest priorities",
                instruction = "Review tasks and identify which should be done first based on typical work patterns",
                allTasks = todos
            });
        }
    }
}

PART 4: HOW MCP PRIMITIVES WORK IN PRACTICE
================================================================================

4.1 PRIMITIVE WORKFLOW
══════════════════════

When you ask Claude something, here's what happens:

USER INPUT: "Show me all my pending tasks and suggest priorities"

STEP 1: Claude analyzes the request
   - Recognizes you want task information (RESOURCE)
   - Recognizes you want analysis (PROMPT)

STEP 2: Claude uses RESOURCES
   - Calls Resource: todo://tasks
   - Server returns all task objects
   - Result: List of TodoItem objects

STEP 3: Claude uses TOOLS (if needed)
   - If you said "create a task", it would call create_task TOOL
   - If you said "mark complete", it would call complete_task TOOL
   - In this case, no TOOLS needed - just reading data

STEP 4: Claude uses PROMPTS
   - Activates: task_priority PROMPT
   - Template provides context for analysis
   - Claude analyzes tasks using the prompt
   - Generates suggestions for you

STEP 5: Claude returns combined result
   - Shows you the tasks (from RESOURCE)
   - Shows you priorities (from PROMPT analysis)
   - All in one conversational response

4.2 FLOW DIAGRAM
═════════════════

USER: "Create a task and show me all tasks"
    ↓
CLAUDE: "I'll use the create_task TOOL and get_all_tasks RESOURCE"
    ↓
┌─── TOOL EXECUTION ─────────┐
│ Tool: create_task          │
│ Input: title, description  │
│ Output: New TodoItem       │
└─────────────────────────────┘
    ↓
┌─── RESOURCE RETRIEVAL ─────┐
│ Resource: todo://tasks     │
│ Output: All TodoItem[]     │
└─────────────────────────────┘
    ↓
CLAUDE COMBINES RESULTS
    ↓
RESPONSE TO USER:
"✓ Created new task
 Here are all your tasks:
 1. Task 1
 2. Task 2
 3. New Task (just created)"

┌──────────┬─────────────────┬──────────────────┬──────────────────────┐
│ Primitive│ Purpose         │ How Claude Uses  │ Example              │

├──────────┼─────────────────┼──────────────────┼──────────────────────┤
│  TOOLS   │ Perform actions │ CREATE/UPDATE    │ "Create a task"      │

│ PROMPTS  │ Analyze/suggest │ PROCESS results  │ "Suggest priorities" │
│          │ Template logic  │ Provide context  │ "Analyze workload"   │
│          │ Pre-built tasks │ Guide behavior   │ "Summarize tasks"    │
└──────────┴─────────────────┴──────────────────┴──────────────────────┘

HOW THEY WORK TOGETHER:

1. RESOURCES provide the DATA
   └─ "Here's what I know"

2. TOOLS perform ACTIONS
   └─ "Here's what I can do"

3. PROMPTS guide ANALYSIS
   └─ "Here's how to think about it"

EXAMPLE FLOW:
┌─────────────────────────────────────────────────────────┐
│ User: "Create a task and show me what's overdue"       │
└─────────────────────────────────────────────────────────┘
         │
         ├─→ TOOL: create_task (Does action)
         │   └─ Creates: "Review project"
         │
         ├─→ RESOURCE: todo://tasks (Gets data)
         │   └─ Returns: All tasks including new one
         │
         ├─→ PROMPT: task_priority (Analyzes)
         │   └─ Identifies: What's overdue/critical
         │
         └─→ RESPONSE: "✓ Created task. Here's your
                         overdue work: [list]"
